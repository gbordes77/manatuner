Correction retenue : `# Deck:,"Persona, ""White"""`. Le marqueur est le premier champ, le nom est une vraie seconde cellule RFC CSV. Les CR/LF sont écrits en caractères littéraux\r/\n pour maintenir une ligne physique ; JSON conserve l'identité complète. csvText protège un nom débutant par un marqueur de formule et garde la virgule interne dans sa cellule. Exemple Safe,=1+1 reste une cellule unique, pas une formule supplémentaire.
